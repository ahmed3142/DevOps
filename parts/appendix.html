A.2 Verifying the artefacts

git clone https://github.com/imranneta5555/DevOps.git && cd DevOps
git log --graph --oneline --all     # branches, merges and commit history
git tag -n1                         # annotated release tag

npm ci && npm run lint && npm test && npm run build
docker compose up --build           # container becomes "healthy" via /api/health

curl localhost:3000/api/health
curl -X POST localhost:3000/api/notes -H 'Content-Type: application/json' -d '{"text":"hello"}'

The GitHub Actions tab records the pipeline runs for main and for the v1.0.0 tag. The application deliberately remains trivial: as the brief notes, the assessment concerns the delivery artefacts and their justification rather than the complexity of the product.
